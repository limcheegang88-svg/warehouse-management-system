# Warehouse Management System Demo

This repository contains a lightweight enterprise warehouse management demo built with React + Vite.

## Features

- Dashboard overview
- Inventory table with stock status
- Inbound stock workflow
- Outbound stock workflow
- Stock take workflow
- Warehouse summary and reports
- Editable mock data for rapid iteration

## Local development

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open the local URL shown in the terminal (usually http://localhost:3000)

## Production build

npm run build

## Customization ideas

- Add backend API and database
- Connect to ERP or order systems
- Add user roles and permission control
- Add barcode scanning and mobile support
- Expand reports and forecasting
